The project will follow the Agile Scrum methodology with weekly sprints. Each sprint delivers a working feature that can be tested and reviewed.


| Week | Tasks                                                      | Deliverables      |

| 2    | Authentication & User Roles                                | Login/Register    |
| 3    | Ticket CRUD                                                | Ticket Module     |
| 4    | Assignment Workflow                                        | Ticket Assignment |
| 5    | Notifications & Dashboard                                  | Dashboard         |
| 6    | Reports & AI Integration                                   | Reporting Module  |
| 7    | Testing & UI Improvements                                  | Stable Version    |
| 8    | Deployment & Documentation                                 | Final Project     |
