Project Overview



The IT Help Desk \& Ticketing Management System is a web-based application that helps organizations manage IT support requests. Employees can create and track support tickets, while IT Support, Managers, and Administrators can assign, manage, and resolve tickets through a centralized system. The project aims to improve communication, reduce response time, and organize technical support operations.



Functional Requirements

* User registration and login with role-based access.
* Create, edit, and track support tickets.
* Assign tickets to IT Support agents.
* Update ticket status (Open, In Progress, Pending, Resolved, Closed).
* Add comments and upload attachments.
* Receive notifications for ticket updates.
* View dashboards and reports.
* Admin management of users, roles, and categories.

Non-Functional Requirements

* Secure authentication using JWT.
* Responsive and user-friendly interface.
* Fast system performance.
* Role-based authorization.
* Reliable database storage and activity logging.

User Roles

* Employee: Create and track tickets.
* IT Support: Manage and resolve assigned tickets.
* Manager: Monitor tickets and view reports.
* Admin: Full system management.

Project Objectives

* Simplify IT support management.
* Improve communication between employees and IT staff.
* Track support requests from creation to resolution.
* Generate reports for monitoring and decision-making.
* Provide a secure and scalable help desk solution.
